# Student Management System – C++

A simple **Student Management System** developed using **C++** as an **MCA Semester 1 project**.

## About the Project

This project is designed to manage student-related information using a C++ console-based application. It provides basic operations for managing students, courses, departments, teachers, and fees.

The project uses **CSV and TXT files** to store and manage data.

## Technologies Used

* C++
* File Handling
* CSV Files
* TXT Files
* Console Application

## Features

* Student management
* Course management
* Department management
* Teacher management
* Fee management
* File-based data storage
* Search and manage records

## Project Files

| File                        | Description          |
| --------------------------- | -------------------- |
| `CLG_MAGEMENET_DRASHTI.cpp` | Main C++ source code |
| `students.csv`              | Student records      |
| `courses.csv`               | Course records       |
| `departments.csv`           | Department records   |
| `teachers.csv`              | Teacher records      |
| `fees.csv`                  | Fee records          |
| `teacher_code.txt`          | Teacher-related data |

## How to Run

1. Download or clone this repository.
2. Open `CLG_MAGEMENET_DRASHTI.cpp` in a C++ IDE such as VS Code, Code::Blocks, or Visual Studio.
3. Compile the program.
4. Run the generated executable.
5. Make sure the required CSV and TXT files are in the same folder as the program.
